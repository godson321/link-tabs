开链助手

普通左键点击链接、拖动链接到页面空白处，或拖动选中的文字时，按下面的规则决定标签页的打开方式。网址规则优先于域名规则；同类规则按列表顺序匹配，第一条命中的规则生效；都没命中时使用该功能各自的全局默认行为。总开关在工具栏弹窗中；搜索引擎与 TIM 链接修复在本页与弹窗中均可设置。

全局默认行为

没有规则命中时使用；三个功能可以分别设置。

搜索引擎

拖动选中的文字搜索时使用；“自定义”可填写任意搜索地址，%s 为搜索词占位符。

TIM 链接修复

把 TIM 卡片分享链接（ssl.ptlogin2.qq.com/jump…）替换为其中的真实地址，避免打开时 403。

规则

按顺序匹配，第一条命中的规则生效：先检查全部网址规则，再检查域名规则；表格按此顺序排列。拖动文字搜索按当前所在页面的网址/域名匹配。

动作：后 = 后台新标签页，前 = 前台新标签页，原 = 按浏览器原行为。列头：点击 = 点击链接；拖动 = 拖动链接到空白处松手；划词 = 拖动选中的文字搜索（按当前页面匹配）；列头复选框 = 该功能的全局启停。
