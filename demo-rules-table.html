后台新标签页 · 规则区域样式演示

这是静态样式稿（mockup），用于确认“合并表格 + 列头全局启停 + 三列复选框 + 缩写动作 + 图标删除 + 弹窗新增”的布局；核对后方才实现到扩展中。

请重点确认（演示中已按以下方式绘制）：
  1. 域名规则与网址规则合并为一张表，用“类型”列区分；
  2. 表格三个功能列（列头精简为：点击 / 拖链接 / 拖文字，悬停或见卡片内图例可看全称），每格一个复选框，勾选/取消即时保存；
  3. 列头复选框 = 该功能的全局启停：取消后该功能在所有网站整体停用，该列行内勾选变灰并停用（原值保留），重新勾选即恢复——点一下列头试试效果；
  4. 规则只提供“删除”图标按钮（悬停变红；无编辑、上移、下移）；修改规则 = 删除后重新添加；
  5. 匹配顺序保持现状：先按顺序检查全部网址规则，再检查域名规则（表格按此顺序排列，中间有分隔行）；组内顺序即添加顺序；
  6. 新增规则改为弹窗：点右上角“添加规则”打开，含类型切换、动作与“作用于”三项勾选；三项全不勾时弹窗内提示错误、不关闭；
  7. 功能开关卡片与搜索引擎卡片已移除（全局启停并入表格列头；搜索引擎移到工具栏弹窗，见 demo-popup.html）；
  8. 动作列用单字缩写：后 = 后台新标签页，前 = 前台新标签页，原 = 按浏览器原行为（悬停显示全称，图例在规则卡片内）；
  9. 页面最大宽度由 760px 调整为 920px 以便容纳表格。

全局默认行为

规则

按顺序匹配，第一条命中的规则生效：先检查全部网址规则，再检查域名规则；表格按此顺序排列。拖动文字搜索按当前所在页面的网址/域名匹配。

动作：后 = 后台新标签页，前 = 前台新标签页，原 = 按浏览器原行为。列头：点击 = 点击链接；拖链接 = 拖动链接到空白处松手；拖文字 = 拖动选中的文字搜索（按当前页面匹配）；列头复选框 = 该功能的全局启停。
