# 后台新标签页

一个 Microsoft Edge（Manifest V3）扩展：普通左键点击网页链接时，在新标签页中打开链接而不切离当前页面。默认行为是 **后台新标签页**——新建标签页但不激活它，当前标签页保持选中。扩展安装后默认启用，可在工具栏弹窗中一键停用。

## 功能行为

- **全局默认行为：** 没有任何规则命中时使用，初始值为“后台新标签页”。
- **总开关：** 位于工具栏弹窗（“启用扩展”）。停用后链接恢复浏览器和网站原有行为，已保存的设置不会被删除；重新开启后设置照常生效。
- **设置页：** 可修改全局默认行为，并添加、编辑、排序或删除域名规则与网址规则。

### 三种动作

全局默认行为和每条规则都可选择以下三种动作之一：

| 动作 | 行为 |
|---|---|
| 后台新标签页 | 在新标签页中打开链接但不激活，当前标签页保持选中。 |
| 前台新标签页 | 在新标签页中打开链接并立即激活该标签页。 |
| 按浏览器原行为 | 不拦截点击，由网站和浏览器按原有方式处理。 |

## 规则与优先级

匹配顺序固定为：

1. 按列表顺序检查**网址规则**；
2. 再按列表顺序检查**域名规则**；
3. 都没命中时使用**全局默认行为**。

即：网址规则优先于域名规则；同一类规则按用户在设置页中排列的顺序匹配，**第一条命中的规则生效**（可用“上移 / 下移”调整顺序）。

### 域名规则

默认只匹配完全相同的域名（`example.com` 不匹配 `www.example.com`，也不匹配 `notexample.com`）；勾选“包含子域名”后，该域名的所有子域名也一起匹配。域名比较不区分大小写。

### 网址规则

填写 `http://` 或 `https://` 开头的模式，`*` 匹配零个或多个字符，例如 `https://example.com/private/*`。模式按 glob 语义匹配**浏览器序列化后的完整 href**（含路径、查询与片段）；主机名比较不区分大小写，路径与查询区分大小写。

> **注意：** 模式匹配的是完整 href。浏览器会把网址规范化为主机名后至少带一个 `/`（`https://example.com` 实际是 `https://example.com/`），因此以域名结尾的模式（如 `https://example.com`）匹配不到任何链接。查询与片段同样属于被匹配的内容：字面模式 `https://example.com/page` 匹配不到 `https://example.com/page?x=1`，末尾加 `*`（如 `https://example.com/page*`）才是稳妥写法。要表示“整个站点”，请写成 `https://example.com/*`。

## 权限与隐私

- **所有网站的访问权限（`http://*/*`、`https://*/*`）：** 扩展通过内容脚本拦截所有普通网站上的普通链接点击，必须能在这些页面中运行，因此需要广泛的站点访问权限。这是实现“在任何网站上左键点击即按规则打开”的必要代价。
- **存储权限（`storage`）：** 用于在 `chrome.storage.local` 中保存用户设置。
- **隐私边界：** 扩展不包含分析功能、不发起任何远程请求、不收集浏览历史；除用户自己填写的设置外不保存任何数据，且这些设置只存放在本机浏览器的扩展存储中。

## 处理范围与例外

以下情况保留浏览器原生行为，扩展不做拦截：按住 Ctrl/Shift/Alt/Meta 的点击，中键与右键点击，带 `download` 属性的下载链接，非 HTTP/HTTPS 链接（如 `mailto:`、`javascript:`），以及同一文档内的片段跳转（如 `#section`）。

扩展也无法作用于浏览器受保护的页面（如 `edge://` 页面和 Edge 加载项商店），并且只处理 `<a href>` 链接上的点击，不处理由按钮触发的脚本跳转。

## 运行测试

需要已安装 Node.js ≥ 18（测试使用 Node 内置测试运行器 `node --test`，无第三方依赖，无需 `npm install`；本项目在 Node.js v25 上验证通过）：

```bash
npm test
```

## 在 Edge 中加载

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目根目录（即包含 `manifest.json` 的目录）。

加载后建议手动确认：

- 普通左键点击链接时，新标签页在后台打开，且当前标签页保持选中；只有“前台新标签页”动作会切换当前标签页。
- 弹窗总开关：停用后链接恢复浏览器原行为，重新启用后已保存的规则仍然生效。
- 设置页中网址规则优先于域名规则，同类规则按排列顺序第一条命中生效。
- 带修饰键的点击、下载链接、非 HTTP/HTTPS 链接和同页片段跳转保持原生行为。
