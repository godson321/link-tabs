# 开链助手

Microsoft Edge（Manifest V3）扩展：左键点击链接、把链接拖到页面空白处、或把选中的文字拖到空白处，都按规则在新标签页打开——默认**后台打开**，当前页不跳走。

## 功能

| 序号 | 触发方式 | 行为 |
|---:|---|---|
| 1 | 点击链接 | 按规则在新标签页打开 |
| 2 | 拖动链接到页面空白处松手 | 同上 |
| 3 | 拖动选中的文字到空白处松手 | 选区完整覆盖可拦截链接，或文字本身是完整 HTTP(S) URL 时直接打开；其他文字用所选搜索引擎搜索（Bing / Google / 百度 / 自定义） |

三种动作，全局默认与每条规则都可选：**后台新标签页**（默认）、**前台新标签页**、**按浏览器原行为**。

| 序号 | 设置项 | 位置 |
|---:|---|---|
| 1 | 规则表：域名规则与网址规则（网址规则优先，同类按顺序、第一条命中生效）；每条规则可单独指定只作用于“点击 / 拖动 / 划词”中的哪几项 | 设置页 |
| 2 | 全局默认行为（三个功能可分别设置）；规则表列头复选框 = 该功能的全局启停 | 设置页 |
| 3 | TIM 链接修复：把 `ssl.ptlogin2.qq.com/jump…` 换成其中的真实地址，避免 403（不受总开关影响） | 设置页 |
| 4 | 总开关、搜索引擎 | 工具栏弹窗 |

以下情况保持浏览器原生行为：带 Ctrl/Shift/Alt/Meta 的点击，中键与右键，下载链接，非 http(s) 链接，同页 `#` 跳转；拖到浏览器界面或窗口外，拖进网页文本框或编辑器。扩展不收集数据、不发起远程请求，设置只存在本机。

## 加载

1. `edge://extensions` → 打开“开发人员模式” → “加载解压缩的扩展” → 选择本目录（含 `manifest.json`）。
2. 需要支持本地 `file://` 页面时，在该扩展详情页开启“允许访问文件 URL”。
3. 重新加载或更新扩展后，刷新已打开的页面（旧页面里的脚本会失效）。

## 开发

```bash
npm test    # 单元测试，使用 Node 内置 runner，无第三方依赖
```

- `tools/drag-harness.html`：用 Edge 打开即可运行拖拽接线测试台（14 项断言）。它只验证事件接线与状态记账，**不验证**光标外观、浏览器是否导航、文本是否真的插入输入框——这三项要在真实浏览器里手动拖动确认。
- `tools/` 还包含图标流水线：图形本体是 `tools/icon-render.html`（纯 SVG），改完按 `tools/make-icons.mjs` 头部注释重新生成 `icons/`。
- 仓库内任何位置都不要放 `_` 开头的文件或目录——Chromium 保留该命名，会让 Edge 拒绝加载扩展；临时文件请放系统临时目录。
