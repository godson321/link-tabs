# 开链助手

一个 Microsoft Edge（Manifest V3）扩展「开链助手」：普通左键点击网页链接时，在新标签页中打开链接而不切离当前页面。默认行为是 **后台新标签页**——新建标签页但不激活它，当前标签页保持选中。扩展安装后默认启用，可在工具栏弹窗中一键停用。

## 功能行为

- **全局默认行为：** 没有任何规则命中时使用，**三个功能（点击链接 / 拖动链接 / 拖动文字搜索）可以分别设置**，初始值都是“后台新标签页”。
- **总开关：** 位于工具栏弹窗（“启用扩展”）。停用后链接恢复浏览器和网站原有行为，已保存的设置不会被删除；重新开启后设置照常生效。（TIM 卡片链接修复由独立开关控制——弹窗与设置页均可设置，不受总开关影响。）
- **搜索引擎：** 可在工具栏弹窗或设置页中选择（Bing / Google / 百度），也可选“自定义”并填写搜索地址（`%s` 为搜索词占位符），用于“拖动文字搜索”。
- **TIM 卡片链接修复：** TIM 分享卡片里的 `ssl.ptlogin2.qq.com/jump...` 链接在浏览器中打开会报 403；扩展会自动改用链接中 `u1` 参数指向的真实地址（点击、拖拽、直接打开均生效；可在工具栏弹窗或设置页中用“TIM 链接修复”开关单独控制，不受总开关影响）。若链接缺少或无法解码 `u1`，则保持原样处理（可能显示 403 或浏览器错误页）。
- **设置页：** 规则表格统一管理域名/网址规则（“添加规则”弹窗新增、图标按钮删除，列头复选框控制三块功能的全局启停），并可分别设置三个功能的全局默认行为、搜索引擎与 TIM 链接修复。

### 三种动作

全局默认行为和每条规则都可选择以下三种动作之一：

| 动作 | 行为 |
|---|---|
| 后台新标签页 | 在新标签页中打开链接但不激活，当前标签页保持选中。 |
| 前台新标签页 | 在新标签页中打开链接并立即激活该标签页。 |
| 按浏览器原行为 | 不拦截点击，由网站和浏览器按原有方式处理。 |

### 拖拽打开链接与文字搜索

按住左键把链接拖到页面空白处松手，按规则打开新标签页（没有规则命中时用“拖动链接时”的全局默认行为）；拖动**选中的文字**到空白处松手，则用所选搜索引擎（弹窗与设置页中均可选 Bing / Google / 百度或自定义搜索地址，默认 Bing）搜索该文字，超长内容取前 500 个字符。拖动过程中，页面空白处的光标显示为可放置样式（复制 / 链接）而不是禁止符号；悬停在网页自己的放置区、输入框或编辑器上时保持网站原生光标。以下情况保持原生行为：释放在网页自带的放置区（编辑器、上传框等）时由网站接收；释放在浏览器界面（收藏夹栏、标签栏、地址栏）或窗口外；带 Ctrl/Shift/Alt/Meta 修饰键的拖动；拖动链接中的图片；在输入框或编辑器内部选中并拖动（移动文字）。若网页整体接管了拖放（如在线文档、网盘类页面），扩展保持不介入。已知限制：拖拽中按 Esc 取消无法与“在空白处松手”区分，可能仍会打开新标签页；网页若只监听 `drop` 而不接受 `dragover`（非标准写法），扩展会在它接收拖放的同时也打开新标签页；极快地甩动后立刻松手时，若浏览器没在落点派发过悬停事件，扩展会保守地不打开标签页。

## 规则与优先级

匹配顺序固定为：

1. 按列表顺序检查**网址规则**；
2. 再按列表顺序检查**域名规则**；
3. 都没命中时使用**该功能的全局默认行为**。

即：网址规则优先于域名规则；同类规则按表格中的先后顺序（即添加顺序）匹配，**第一条命中的规则生效**。

每条域名/网址规则还可分别勾选**作用的功能**：点击链接 / 拖动链接 / 拖动文字搜索（新建规则时默认全选；至少要勾选一项；表格列头缩写为“点击 / 拖动 / 划词”，悬停显示全称）。例如，一条 `example.com → 按浏览器原行为` 且只勾选“点击链接”的规则，只会让点击该站链接保持原生，拖动链接与在该站拖动文字搜索照常工作。拖动文字搜索按**当前所在页面**的网址/域名匹配规则。

表格三个功能列的**列头复选框是该功能的全局启停**：取消后该功能在所有网站整体停用（该列行内勾选变灰、原值保留），重新勾选即恢复。修改规则 = 删除后重新添加。

### 域名规则

默认只匹配完全相同的域名（`example.com` 不匹配 `www.example.com`，也不匹配 `notexample.com`）；勾选“包含子域名”后，该域名的所有子域名也一起匹配。域名比较不区分大小写。

### 网址规则

填写 `http://` 或 `https://` 开头的模式，`*` 匹配零个或多个字符，例如 `https://example.com/private/*`。模式按 glob 语义匹配**浏览器序列化后的完整 href**（含路径、查询与片段）；主机名比较不区分大小写，路径与查询区分大小写。

> **注意：** 模式匹配的是完整 href。浏览器会把网址规范化为主机名后至少带一个 `/`（`https://example.com` 实际是 `https://example.com/`），因此以域名结尾的模式（如 `https://example.com`）匹配不到任何链接。查询与片段同样属于被匹配的内容：字面模式 `https://example.com/page` 匹配不到 `https://example.com/page?x=1`，末尾加 `*`（如 `https://example.com/page*`）才是稳妥写法。要表示“整个站点”，请写成 `https://example.com/*`。

## 权限与隐私

- **所有网站的访问权限（`http://*/*`、`https://*/*`）：** 扩展通过内容脚本拦截所有普通网站上的普通链接点击，必须能在这些页面中运行，因此需要广泛的站点访问权限。这是实现“在任何网站上左键点击即按规则打开”的必要代价。扩展同时支持本地 `file://` 页面（需在扩展详情页开启“允许访问文件 URL”）。
- **存储权限（`storage`）：** 用于在 `chrome.storage.local` 中保存用户设置。
- **请求拦截与导航权限（`declarativeNetRequestWithHostAccess`、`webNavigation`）：** 仅用于识别并拦下 `ssl.ptlogin2.qq.com/jump` 这一条路径的打开请求，并跳转到其真实目标；不读取、不修改其他任何请求。
- **隐私边界：** 扩展不包含分析功能、不发起任何远程请求、不收集浏览历史；除用户自己填写的设置外不保存任何数据，且这些设置只存放在本机浏览器的扩展存储中。

## 处理范围与例外

以下情况保留浏览器原生行为，扩展不做拦截：按住 Ctrl/Shift/Alt/Meta 的点击，中键与右键点击，带 `download` 属性的下载链接，非 HTTP/HTTPS 链接（如 `mailto:`、`javascript:`），以及同一文档内的片段跳转（如 `#section`）。

扩展也无法作用于浏览器受保护的页面（如 `edge://` 页面和 Edge 加载项商店），并且只处理 `<a href>` 链接上的点击，不处理由按钮触发的脚本跳转。本地 `file://` 页面需在扩展详情页开启“允许访问文件 URL”后才会生效。

## 图标

扩展图标（`icons/`，16/32/48/128 PNG，蓝色圆角底板 + 白色链环图形，不含任何文字）由 `tools/` 中的流水线生成：图形本体是 `tools/icon-render.html`（纯 SVG），改完图形后按 `tools/make-icons.mjs` 头部注释里的命令渲染母图，再执行 `node tools/make-icons.mjs` 缩放输出。生成过程只用 Node 内置模块，无第三方依赖。

## 运行测试

需要已安装 Node.js ≥ 18（测试使用 Node 内置测试运行器 `node --test`，无第三方依赖，无需 `npm install`；本项目在 Node.js v25 上验证通过）：

```bash
npm test
```

另有一个浏览器内的拖拽接线测试台 `tools/drag-harness.html`：用 Edge 直接打开该文件即可运行，它用合成拖拽事件复核内容脚本的悬停 / 落地接线（14 项断言，覆盖 `node --test` 够不到的 DOM 事件顺序、`defaultPrevented` 判断与拖放归属）。它只验证事件接线与状态记账，**不验证**光标外观、浏览器是否导航、文本是否真的插入输入框——这三项需要在真实浏览器里手动拖动确认。

> 注意：扩展目录树的任何位置（尤其仓库根目录）都不要放以 `_` 开头的文件或目录——Chromium 把该命名保留给系统使用，一旦出现，Edge 会直接拒绝加载扩展并报 `Cannot load extension with file or directory name _xxx`。临时文件（截图、脚本、日志）请放到系统临时目录。

## 在 Edge 中加载

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目根目录（即包含 `manifest.json` 的目录）。
5. 如需支持本地 `file://` 页面，在该扩展的详情页开启“允许访问文件 URL”。

> 提示：重新加载或更新扩展后，请刷新已打开的页面——旧页面里的脚本会失效（此时点击/拖拽保持原生行为，并在控制台提示刷新；刷新后恢复）。

加载后建议手动确认：

- 普通左键点击链接时，新标签页在后台打开，且当前标签页保持选中；只有“前台新标签页”动作会切换当前标签页。
- 弹窗总开关：停用后链接恢复浏览器原行为，重新启用后已保存的规则仍然生效。
- 设置页中网址规则优先于域名规则，同类规则按排列顺序第一条命中生效。
- 设置页：把“拖动链接时”的全局默认行为改成“按浏览器原行为”后，拖动链接不再拦截；但规则里勾了“拖动”的站点仍按规则生效（全局默认只管没有规则命中的情况）。
- 带修饰键的点击、下载链接、非 HTTP/HTTPS 链接和同页片段跳转保持原生行为。
- 拖拽：把链接拖到页面空白处松手 → 按规则打开新标签页；拖动时空白处光标为可放置样式（不是禁止符号）；拖到收藏夹栏 → 只建书签、不开标签页；拖进网页文本框 → 原生插入、不开标签页；Ctrl+拖动保持原生。
- 文字搜索：选中一段文字拖到页面空白处松手 → 按所选搜索引擎打开搜索标签页；在输入框或编辑器内选中并拖动 → 原生移动文字，不搜索。
- 设置页：规则表格的列头复选框与行内勾选分别生效（例如“仅点击”的规则不影响拖动；取消列头“拖文字”后拖动文字不再搜索）；“添加规则”弹窗校验输入，三项功能全不勾时提示错误、不保存。
- 弹窗：切换搜索引擎后地址框随之变化（预设只读、自定义可编辑）；自定义地址非法（非 http(s) 开头或缺 %s）时提示错误且不保存。
- TIM 卡片链接：打开一条 `ssl.ptlogin2.qq.com/jump...` 链接 → 直接到达 `u1` 参数指向的真实页面，不出现 403。
- 弹窗开关：关闭“TIM 链接修复”后，此类链接恢复原样（可能显示 403）；重新开启后恢复修复。
- 设置页：切换搜索引擎（含自定义地址）与 TIM 链接修复开关 → 与工具栏弹窗共享同一份设置；在任一处修改后，另一处刷新即显示一致。
